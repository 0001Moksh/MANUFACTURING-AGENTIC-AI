# Permit Data Requirement for Video Analytics → Safety Permit Compliance Agent

## Purpose

This document is for the Video Analytics project developer.

We need the Video Analytics system to store **work permit information in the Video Analytics / `construction_ai` PostgreSQL database** so that our Agentic AI can read the permit records and correlate them with live camera/video analytics data.

The external Video Analytics database will be treated as **READ ONLY by our Agent**. The Video Analytics application/developer will be responsible for creating and maintaining the permit records.

---

## 1. Agent Requirement

The agent must support:

- Hot Work permit tracking
- Confined Space permit tracking
- Work-at-Height permit tracking
- Permit validity checking
- Worker-to-permit matching
- Camera/zone-to-permit matching
- Time-based permit validation
- Permit status validation
- Detection of work being performed without a valid permit
- Detection of work continuing after permit expiry/revocation
- Correlation of permit data with PPE / behavior / safety violations
- Automatic violation escalation through the existing HSE alert/incident workflow

### Basic decision

The agent should be able to answer:

> "Is this worker currently performing this type of hazardous work in this camera/zone, and does that worker have a valid permit for that activity at this time?"

---

# 2. Required Permit Table

Please create a table in the Video Analytics / `construction_ai` database.

Recommended table name:

`work_permits`

The table should contain at least the following information.

| Field | Required | Purpose |
|---|---|---|
| `id` | Yes | Unique database ID |
| `permit_number` | Yes | Unique permit/reference number |
| `permit_type` | Yes | `HOT_WORK`, `CONFINED_SPACE`, `WORK_AT_HEIGHT` |
| `employee_id` | Yes | Worker/employee identifier |
| `zone_id` | Yes | Zone/location where permit is valid |
| `work_description` | Yes | Description of permitted work |
| `valid_from` | Yes | Permit start date/time |
| `valid_until` | Yes | Permit expiry date/time |
| `status` | Yes | `ACTIVE`, `EXPIRED`, `REVOKED`, `CLOSED`, `PENDING` |
| `approved_by` | Recommended | Safety officer/supervisor who approved it |
| `approved_at` | Recommended | Approval timestamp |
| `ppe_requirements` | Recommended | PPE required for the permit |
| `safety_conditions` | Recommended | Safety controls/conditions required |
| `emergency_contact` | Optional | Responsible person/contact |
| `remarks` | Optional | Additional instructions |
| `created_at` | Yes | Record creation timestamp |
| `updated_at` | Yes | Last update timestamp |
